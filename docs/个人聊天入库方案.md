# 个人聊天入库

## 背景

用户收到很多工作相关的报价文件是通过个人聊天发送的。当前 `sync_engine.py` 在两处硬过滤 `chat_type != "group"` 跳过个人消息，这些工作信息无法在仪表盘上查看和管理。

## 方案

在现有 `groups` 表上扩展（加 `chat_type` 列），最小化改动：

| 层 | 文件 | 改动 |
|---|------|------|
| 数据库 | `backend/database.py` | ALTER TABLE 加 `chat_type` 列；`upsert_group`/`get_all_groups`/`get_categories`/其他函数支持 `chat_type` |
| 同步 | `backend/sync_engine.py` | 去掉 `chat_type` 过滤；新增个人聊天发现和存储 |
| API | `backend/app.py` | `/api/groups` 支持 `chat_type` 参数；个人聊天设置只读 |
| 前端 | `static/app.js` | 新增"个人"标签页；个人聊天隐藏群摘要/关键信息标签页 |
| 模板 | `templates/dashboard.html` | 表头"群主"→"群主/联系人" |

## 实施步骤

### 1. 数据库 schema 变更 (`database.py`)

- **`init_db()`**：新增 `ALTER TABLE groups ADD COLUMN chat_type TEXT DEFAULT 'group'`
- **`upsert_group()`**：签名增加 `chat_type='group'`，INSERT 包含 `chat_type`
- **`get_all_groups()`**：增加 `chat_type` 参数；默认 `chat_type='group'`
- **`get_categories()`**：如有个人聊天存在，结果前插入 `"个人"`
- **`get_groups_for_classification()`**：WHERE 加 `AND g.chat_type='group'`
- **`get_groups_for_incremental_extraction()`**：同理
- **`get_all_group_names()`**：同理  
- **`get_undownloaded_file_messages()`**：同理
- **`get_group_message_stats()`**：同理

### 2. 同步引擎 (`sync_engine.py`)

- **`_discover_new_groups()`**：同时处理 `private` 类型会话。个人聊天不走关键词推断，直接 `upsert_group(name, "个人", project="个人", chat_type='personal')`
- **`sync()`**：消息分组时增加 `private` 分支，不过滤关键词，按聊天名分组
- **新增 `_store_personal_messages()`**：简化版 `_store_group_messages`，category 固定"个人"

### 3. API (`app.py`)

- **`/api/groups`**：支持 `?chat_type=personal`
- **`/api/groups/<id>/settings`**：`chat_type='personal'` 时设为只读

### 4. 前端 (`app.js`)

- 常量增加 `PERSONAL_CAT = '个人'`
- `renderTabs()`：在全部标签后插入"个人"标签（加分割线）
- `loadAll()`：用 `Promise.all` 同时加载项目群和个人聊天
- `setActiveTab()`：切换到"个人"时调用 `?chat_type=personal`
- `renderTable()`：个人聊天"群主"列显示"--"
- `openDrawer()`：个人聊天隐藏"群摘要"和"关键信息"标签页
- `updateCategoryFilterOptions()`：个人标签页隐藏分类下拉
- `refreshCurrentView()`：同样 `Promise.all` 加载

### 5. 模板 (`dashboard.html`)

- 表头 `<th>群主</th>` → `<th>群主/联系人</th>`

## 验证

1. 启动应用后检查数据库 `PRAGMA table_info(groups)` 确认 `chat_type` 列存在
2. 手动触发同步，检查 sync_log 中是否出现"发现个人聊天"
3. 数据库查询 `SELECT * FROM groups WHERE chat_type='personal'` 确认记录入库
4. 前端点击"个人"标签页，确认列表显示、抽屉正常、AI 标签页隐藏
5. 切换回群标签页，确认回归正常
